# 사건 대시보드 정보구조

## 1. 목적

사건 대시보드는 분석 결과를 나열하는 화면이 아니라, 사용자가 사건의 현재 상태·근거·위험·승인 필요사항·다음 행동을 한눈에 이해하는 작업공간이다.

## 2. 최상위 내비게이션

```text
개요
증거
권리·임차인
건축·현장·명도
시장·입지
금융·비용·수익
모의입찰
승인·감사
실제결과·사후복기
```

## 3. 사건 개요 화면

### 3.1 사건 헤더

- 사건번호
- 법원과 담당계
- 물건 주소·유형
- 매각기일
- 감정가·최저가
- 현재 상태
- 마지막 자료 기준일
- stale·차단·전문가검토 배지

### 3.2 진행 단계

```text
자료수집
→ 권리검토
→ 시장·현장검토
→ 금융·수익검토
→ 모의입찰 후보
→ 사람 승인
→ 잠금
→ 결과 추적
→ 복기
```

각 단계는 다음 상태 중 하나다.

- 미시작
- 진행 중
- 완료
- 조건부 완료
- 차단
- stale
- 전문가검토 필요

### 3.3 핵심 경고

최대 5개의 중요한 경고만 상단에 표시하고 전체 목록은 별도 영역에서 확인한다.

우선순위:

1. 인수 가능 권리·선순위 임차인
2. 특수권리
3. 토지·건물·대지권·지분 문제
4. 위반건축물·점유·명도
5. 자금부족·비용 누락

### 3.4 다음 행동

PM이 생성한 `next_actions` 중 사람이 해야 하는 행동을 표시한다.

- 문서 추가
- 현장 확인
- 금융기관 확인
- 전문가 질문
- 승인 검토

## 4. 증거 화면

### 4.1 Evidence Index

| 증거 ID | 문서 | 기준일 | 상태 | 사용 분석 | 민감도 |
|---|---|---|---|---|---|

상태:

- 원본 확인
- 추출 완료
- 표본검증 완료
- 충돌
- 오래됨
- 읽기불가
- 접근제한

### 4.2 원문과 추출값 비교

사용자는 추출된 사실을 클릭해 원문 위치를 확인할 수 있어야 한다.

```text
Claim
→ Evidence ID
→ Page/Section
→ Extracted text
→ Normalized value
→ Reviewer
```

원문을 수정하지 않고 추출 오류는 새 버전으로 정정한다.

## 5. 권리·임차인 화면

### 5.1 권리 타임라인

날짜순·접수순으로 다음을 표시한다.

- 소유권 변동
- 근저당·압류·가압류
- 경매개시
- 가등기·가처분
- 임차인 점유·전입·확정일자·배당요구
- 변경·이전·말소

각 항목에 `확인`, `후보`, `미확인`, `충돌` 상태를 붙인다.

### 5.2 임차인 표

| 임차인 ID | 점유 | 전입 | 확정일자 | 배당요구 | 보증금 | 대항력 후보 | 인수위험 |
|---|---|---|---|---|---|---|---|

동일 이름이라도 별도 임차인 ID를 유지한다.

### 5.3 Primary vs Counter

- 합의한 내용
- 반대해석
- 누락자료
- Evidence Judge 판정
- 외부전문가 질문

## 6. 건축·현장·명도 화면

### 6.1 공식자료 비교

- 건축물대장
- 감정평가서
- 현장 사진·메모
- 도면
- 위반건축물 정보

면적·용도·세대수·주차·토지지분 불일치를 강조한다.

### 6.2 현장 체크리스트

- 확인 완료
- 사진 필요
- 중개업소·관리사무소 확인
- 기관 확인
- 내부 미확인

### 6.3 명도 시나리오

- 점유자 유형 후보
- 협의·절차 확인사항
- 기간 범위
- 비용 범위
- 법률전문가 필요 여부

확정 명도기간처럼 표시하지 않는다.

## 7. 시장·입지 화면

### 7.1 비교사례 지도·표

- 실거래
- 호가
- 임대등록가
- 경매 낙찰사례

자료 유형을 섞어 평균내지 않는다.

### 7.2 비교 품질

- 거리
- 면적
- 층
- 방향
- 연식
- 상태
- 거래일
- 권리·건축 차이

### 7.3 출구전략

- 실거주
- 임대
- 매도

- 장기보유

각 전략별 기간·유동성·비용·실패조건을 표시한다.

### 9.2 핵심 내용

- 투자 목적

- 자금 요구액

## 11. 실제결과·사후복기

### 11.1 경매결과

- 낙찰·유찰·취하·변경
- 실제 낙찰가
- 입찰자 수
- 매각허가·잔금·재매각

### 11.2 예상 대비 실제

- 낙찰가 오차
- 명도기간 오차
- 수리비 오차
- 금융·세금 오차
- 임대·매도 결과

### 11.3 학습

- 놓친 위험
- 과대평가한 위험
- 새 fixture 후보
- 프롬프트·규칙 개선 후보

학습 후보는 자동 운영반영하지 않고 Evaluation Harness 검토로 보낸다.

## 12. 역할별 화면 차이

### 일반 사용자

쉽게 이해할 수 있는 핵심 위험, 근거와 다음 행동 중심.

### 전문가 검토자

원문 인용, 타임라인, 규칙 버전, 반대해석과 세부 조건 중심.

### 운영·Governance

실행로그, 도구호출, 권한, 비용, 모델·프롬프트 버전과 승인 무결성 중심.

## 13. 알림 원칙

알림 대상:

- 매각기일 변경
- 새 문서·새 등기
- 분석 stale
- 승인 요청
- 조건 미충족
- 정책 만료
- 실제 결과 확인

경미한 에이전트 실행완료 알림을 과도하게 보내지 않는다.
