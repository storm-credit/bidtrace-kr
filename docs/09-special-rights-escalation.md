# 특수권리·고위험 사건 승격 매트릭스

## 1. 목적

일반적인 순위·말소 규칙만으로 처리해서는 안 되는 사건을 조기에 탐지하고, 자동분석을 중단하거나 외부 전문가에게 넘기는 기준을 정의한다.

## 2. 공통 처리

모든 특수권리 신호는 다음 절차를 따른다.

```text
신호 탐지
 → 관련 원문 확보
 → 사실·주장·추정 분리
 → 일반 권리분석 중단 여부 결정
 → 독립 검토
 → 전문분야 지정
 → 사람 승인
```

출력:

```yaml
signal_id: string
category: string
severity: high|critical
confirmed_facts: []
claim_only: []
unknowns: []
required_evidence: []
required_professional: []
automation_status: continue_with_limits|block
bid_state_effect: hold|expert_review_required|exclude_candidate
```

## 3. 승격 매트릭스

### 3.1 유치권 주장

탐지 신호:

- 매각물건명세서·현황조사서의 유치권 기재
- 현수막·공고·점유자 주장
- 공사대금·수리비 채권 주장
- 채권자와 점유자의 관계 불명확

필요자료:

- 점유 시점과 연속성
- 피담보채권의 존재·변제기·물건 관련성
- 공사계약·세금계산서·판결·신고자료
- 현장점유 사실

처리:

- 자동 인수금액 계산 금지
- 변호사 검토 필수
- 현장조사 필수
- `BID_READY` 차단

### 3.2 법정지상권 가능성

탐지 신호:

- 토지와 건물 소유자 불일치
- 저당권 설정 당시와 매각 후 소유분리 가능성
- 건물만 또는 토지만 매각
- 제시외 건물·미등기 건물

필요자료:

- 토지·건물 소유권 변동 타임라인
- 건물 존재 시점
- 담보권 설정 당시 소유관계
- 매각 대상 범위
- 건축물대장·등기·현황

처리:

- 일반 선후순위 규칙으로 결론 금지
- 변호사·법무사 검토
- 필요 시 측량·건축 전문가
- 사용료·철거·존속 가능성을 시나리오로만 표시

### 3.3 지분경매

탐지 신호:

- 매각대상이 전체 소유권이 아닌 지분
- 공유자 점유
- 공유물분할 관련 소송·가처분

필요자료:

- 공유자와 지분율
- 점유·사용관계
- 공유자 우선매수 관련 사건 정보
- 분할 가능성·물건 성격

처리:

- 일반 시세를 지분율만큼 단순 곱하지 않음
- 명도 가능성을 일반 사건과 동일하게 보지 않음
- 법률검토와 별도 환금성 분석

### 3.4 대지권 미등기·불명확

탐지 신호:

- 집합건물인데 대지권 표시 없음
- 토지등기와 건물등기 연결 불명확
- 감정평가와 등기 기재 충돌

필요자료:

- 토지등기
- 집합건축물대장
- 대지권 등록·이전 관련 서류
- 감정평가서의 포함 범위

처리:

- 토지 사용권을 추정하지 않음
- 법무사·변호사 확인
- 금융기관 담보평가 가능성 별도 확인

### 3.5 가등기·가처분

탐지 신호:

- 소유권이전청구권 가등기
- 담보가등기 성격 불명확
- 처분금지·철거·인도 관련 가처분

필요자료:

- 등기 원인
- 피보전권리
- 관련 소송·결정
- 배당요구·채권신고

처리:

- 등기명만으로 말소 여부 자동분류 금지
- 관련 결정문 확인 전 `unknown`
- 법률검토 필수

### 3.6 분묘기지권 가능성

탐지 신호:

- 토지 현황·항공사진·현장에 분묘 존재
- 감정평가서 기재
- 임야·전·답 등 비도시 토지

필요자료:

- 현장 위치와 존재 여부
- 설치 시점과 관리 주체
- 토지 소유·승낙 관련 자료

처리:

- 등기부만으로 부존재 판단 금지
- 현장·법률검토
- 토지 활용가치에 별도 불확실성 반영

### 3.7 제시외 건물·부합물·종물

탐지 신호:

- 감정평가서의 제시외 건물
- 건축물대장과 현황 면적 불일치
- 창고·증축·옥탑·지하공간

필요자료:

- 매각 포함 여부
- 소유관계
- 허가·위반 여부
- 철거·사용 가능성

처리:

- 매각 포함을 추정하지 않음
- 건축사·법무사 확인
- 수리·철거 비용 별도 시나리오

### 3.8 위반건축물·불법 용도변경

탐지 신호:

- 건축물대장 위반 표시
- 현황상 세대수·용도·구조 불일치
- 다가구·다세대 구분 충돌

필요자료:

- 건축물대장 전체
- 현황도면
- 행정처분·이행강제금
- 실제 구조와 임대 세대

처리:

- 건축사·관할 행정기관 확인
- 원상복구·이행강제금·대출 제한 가능성
- 수익분석에서 불법 상태 지속을 기본가정으로 사용 금지

### 3.9 토지·건물 매각범위 불일치

탐지 신호:

- 일부 토지 또는 일부 건물 제외
- 여러 필지 중 일부만 매각
- 도로·통행 부분 제외

필요자료:

- 매각목록
- 지적도·현황도
- 감정평가 포함범위
- 진입·사용 가능성

처리:

- GIS·측량·법률 검토
- 일반 매매 비교사례 사용 제한

### 3.10 농지·산지·토지이용 제한

탐지 신호:

- 농지취득자격증명 등 별도 요건 가능성
- 산지·개발행위·맹지·도로 문제
- 용도지역·행위제한

처리:

- 최신 행정·토지 규정 확인
- 관할기관·토지전문가 문의
- 자격·허가 미확인 시 입찰 준비 완료 금지

## 4. 승격 전문분야

| 쟁점 | 우선 검토자 |
|---|---|
| 인수·말소·가등기·가처분 | 변호사 또는 법무사 |
| 임차인·배당 | 변호사·법무사 |
| 위반건축물·구조 | 건축사·관할 행정기관 |
| 경계·매각범위 | 측량사·법무사 |
| 대출 담보성 | 금융기관 |
| 세금 | 세무사 |
| 농지·산지·개발제한 | 관할 행정기관·토지 전문가 |

## 5. 사람 승인 화면

사람에게 다음을 제공한다.

```text
특수권리 종류
확인된 사실
단순 주장인 내용
필요한 원문
최악의 결과
분석이 멈춘 이유
문의할 전문가와 질문
입찰 준비 상태에 미치는 영향
```

## 6. 평가 기준

- 특수권리 신호 누락률
- 일반규칙으로 잘못 완료한 비율
- 전문가 승격 정확도
- 불필요한 과잉 승격률
- 원문 없는 확정표현 발생률

치명적 특수권리 누락은 P0 또는 P1으로 분류한다.

## 7. 주의

이 매트릭스는 모든 법률요건을 포함하는 규칙집이 아니다. 탐지와 승격을 위한 안전 프레임워크이며 실제 사건은 최신 법령·판례와 전문가 검토가 필요하다.
