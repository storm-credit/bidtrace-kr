# BidTrace KR

한국 부동산 경매의 물건 발굴부터 권리분석, 모의입찰, 실제 낙찰 결과, 낙찰 후 운영과 사후 복기까지 하나의 사건 타임라인으로 관리하는 의사결정 시스템의 기획·설계 저장소입니다.

> 현재 단계는 **기획·설계 전용**입니다. 실제 경매 자동입찰이나 법률적 최종판정을 구현하지 않습니다.

## 핵심 목표

1. 경매 사건마다 사용한 자료와 판단 근거를 추적한다.
2. 권리·임차인·시세·건축·명도·자금·세금·수익 분석을 전문 에이전트로 분리한다.
3. PM 오케스트레이터가 실행 순서, 자료 완성도, 검증과 사람 승인을 통제한다.
4. 모의입찰 당시 판단을 잠그고 실제 낙찰 결과와 비교한다.
5. 예상과 실제의 오차를 누적해 다음 사건의 분석 품질을 개선한다.

## 설계 원칙

- AI는 사실을 단정하지 않고 증거, 가정, 불확실성을 함께 제시한다.
- 날짜 정렬, 비용 합산, 수익률 등 결정적 계산은 규칙 기반 모듈로 분리한다.
- 선순위 임차인, 유치권, 법정지상권, 지분경매 등 고위험 사건은 사람 승인을 필수로 한다.
- Hermes Agent는 선택 가능한 작업자 런타임이며, PM·정책 엔진·증거 저장소가 아니다.
- 모든 프롬프트, 정책, 모델 배정과 평가 결과는 Git으로 버전 관리한다.

## 작업 방식

설계는 `agent/*` 브랜치에서 작은 단위로 커밋하고 Draft PR에서 검증합니다.

예정 문서:

- 제품 제안서와 사용자 여정
- 경매 전체 생애주기와 사건 상태머신
- PM 오케스트레이터 및 에이전트 하네스
- 전문가 에이전트별 프롬프트와 실행 계약
- 모델 라우팅과 비용·안전 정책
- MCP·Skills·Hooks 권한 매트릭스
- 반복 평가·회귀검증·GitHub 거버넌스
- MVP 범위와 구현 로드맵

## 면책

본 프로젝트의 결과는 학습·검토를 위한 의사결정 보조자료입니다. 실제 입찰 전에는 최신 원문 서류와 현장을 확인하고 필요 시 변호사, 법무사, 세무사, 금융기관 등 자격 있는 전문가의 검토를 받아야 합니다.
